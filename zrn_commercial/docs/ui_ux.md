# UI/UX de (ZRN) Manejo Comercial

## Direccion visual

La interfaz debe sentirse:

- administrativa
- clara
- compacta
- alineada con Odoo
- enfocada en mantenimiento de datos

## Reglas visuales

- usar vistas nativas de Odoo antes que HTML custom
- priorizar tablas, formularios y relaciones
- mantener encabezados funcionales y sin texto decorativo
- usar el espacio para editar datos, no para banners
- respetar radios suaves y fondos neutros

## Colores base

En esta primera fase no se necesita una capa visual propia compleja:

- se prioriza la UI nativa de Odoo
- la identidad Zoraen entra despues en dashboards o centros comerciales mas amplios
- los logos de marca deben destacar por su propio contenido, no por contenedores decorativos

## Componentes clave

- tabla principal de marcas comerciales
- formulario de alta y mantenimiento
- pestaña de productos asociados
- estado vacio nativo de Odoo para primera carga

## Criterio de crecimiento

Antes de agregar mas UI:

1. validar si el nuevo frente es comercial operativo y no analitico
2. preferir menus y vistas separadas por dominio
3. mantener la densidad funcional de Odoo
