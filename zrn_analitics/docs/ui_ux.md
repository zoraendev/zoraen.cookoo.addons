# UI/UX de (ZRN) Analitica

## Direccion visual

La interfaz debe sentirse:

- administrativa
- analitica
- clara
- compacta
- alineada con Odoo

## Reglas visuales

- priorizar paneles funcionales y menus cortos
- evitar decoracion excesiva o layouts tipo landing
- usar placeholders sobrios mientras no exista logica real
- mantener contraste alto y lectura rapida
- reservar el ancho para datos y navegacion, no para texto largo

## Colores base

La base visual usa:

- azules Zoraen para acentos principales
- verdes suaves para capas de procesamiento o estado favorable
- fondos blancos y grises claros administrativos
- bordes suaves y separacion simple

## Componentes clave

- centro principal con dos paginas
- menu inicial de hubs, dashboards y procesamiento
- workspace preparado para futuros frentes
- control panel con acceso rapido a la pagina principal

## Criterio de crecimiento

Antes de agregar hubs reales:

1. validar el dominio analitico que vivira en este addon
2. separar la logica por vistas o subfrentes
3. mantener la estetica nativa de Odoo con acentos Zoraen
